🎬 App Lista de Filmes e Séries
📱 Descrição

Aplicativo Android para cadastrar e gerenciar filmes/séries.
O usuário adiciona títulos, marca como assistido e atribui uma nota.

🚀 Funcionalidades

Adicionar título (nome + gênero)

Listagem com RecyclerView

Marcar como assistido

Inserir nota (somente se assistido)

🧠 Estrutura do Item

Nome (String)

Gênero (String)

Já assistido (Boolean)

Nota (Double)

🛠️ Tecnologias

Java / Kotlin

Android Studio

RecyclerView
